# 📰 TechNews - Portal de Notícias sobre Tecnologia

Um portal de notícias moderno e intuitivo focado no ecossistema de tecnologia, desenvolvido com **HTML5** e **CSS3**. O projeto apresenta as últimas novidades, artigos e análises sobre Inteligência Artificial, Desenvolvimento de Software, Gadgets e Segurança da Informação.

---

## 🚀 Funcionalidades

- **Página Inicial (Home):** Notícia de destaque principal, grid de artigos recentes e seção de matérias mais lidas.
- **Navegação por Categorias:** Menu para rápida filtragem de temas (Hardware, Software, IA, Mobile, etc.).
- **Layout Responsivo:** Interface adaptada para navegação em desktops, tablets e smartphones usando Flexbox, Grid e Media Queries.
- **Seção de Newsletter:** Formulário estilizado para captura de e-mails de leitores.
- **Rodapé Informativo:** Links rápidos, termos de uso e redes sociais do portal.

---

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estruturação semântica e acessível das páginas.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilização, layout flexível (Flexbox/Grid), paleta de cores, tipografia e responsividade.
